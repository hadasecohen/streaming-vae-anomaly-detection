# Data License

## Mini ERA5-shaped datasets (`data/era5/`)

The four CSVs under `data/era5/` (`reanalysis-era5-single-levels-timeseries.csv`,
`era5_point_rare.csv`, `era5_contextual_anomalies.csv`, `era5_group_anomalies.csv`)
are fully synthetic. They are generated by `scripts/generate_mini_era5.py` — same
column names as real ERA5 (u100, v100, u10, v10, fg10, d2m, t2m, msl, skt, sp,
ssrd, strd, tp), same hourly cadence, with clean/point/contextual/group
anomaly injection — but the values are synthetic (diurnal + seasonal sinusoids
plus noise), not sampled from real reanalysis data. No license restrictions;
regenerate anytime with `python scripts/generate_mini_era5.py`.

## Real ERA5 reanalysis data

`experiments/era5/` is written for real ERA5 hourly reanalysis data, sourced
from the Copernicus Climate Data Store (CDS): https://cds.climate.copernicus.eu/

Real ERA5 data is distributed under the Copernicus license, which permits
reuse with attribution — check the current terms on the CDS dataset page
before redistributing any derived files. This repository does not include
real ERA5 data; swap `data_path` in any `experiments/era5/**/*.yaml` to point
at your own download to run on the real thing.
